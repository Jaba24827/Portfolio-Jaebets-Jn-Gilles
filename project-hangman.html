Hangman Game

A classic word-guessing game in Java with clean object-oriented logic and validated input.

Overview

A classic Hangman word-guessing game written in Java. It is a compact project that shows clean object-oriented structure, input validation and clear win and lose logic.

What it does

  • Random word selection and letter-by-letter guessing
  • Validated input that ignores repeated or invalid guesses
  • Win and lose detection with a limited number of attempts
