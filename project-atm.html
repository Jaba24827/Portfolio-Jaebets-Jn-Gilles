ATM Transaction System

A desktop ATM with core transactions designed around ACID principles so balances can always be trusted.

Overview

A desktop ATM application that supports basic banking transactions. Its core design goal is data integrity: every operation respects ACID principles so balances can be trusted even when something fails midway.

It is built with C# and WPF for the interface and Microsoft SQL Server for storage.

What it does

  • Atomicity: a transaction completes fully or not at all
  • Consistency: rules keep data valid before and after each operation
  • Isolation: simultaneous operations do not interfere
  • Durability: committed transactions survive failures
