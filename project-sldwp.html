St. Luke Digital Workplace Platform

A secure, role-based digital workplace for a multi-sector nonprofit: two-step sign-in, access control, documents, announcements, and audit trails.

Overview

The St. Luke Digital Workplace Platform is a secure, role-based workspace designed for a multi-sector nonprofit that runs education, healthcare and production programs. It gives staff one place for documents, announcements and daily coordination.

It was built as my capstone project, from requirements and architecture through implementation, automated testing and performance checks. A production deployment is proposed as the next step.

What it does

  • Two-step sign-in (MFA) to protect accounts
  • Role-based access control, so people only see what they need
  • Audit logging to trace important actions
  • Documents and announcements for staff
  • React and TypeScript interface with a Laravel API and MySQL database
